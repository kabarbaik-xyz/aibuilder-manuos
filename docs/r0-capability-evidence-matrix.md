## 3. Discrepancy & Gap Analysis for Release Readiness

1. **Local Integration & Double-Entry Ledger**:
   - All 36 capabilities are wired to real Prisma models, transactional command boundaries (`executeCommand`), and double-entry ledger movements (`postMovement`).
   - Zero simulated mocks, zero floating-point arithmetic.
   - Vitest test suite passes 100% (**399/399 tests across 74 test files**).
   - Reconcile reports **Balanced: ✓ YES (0 discrepancies)**.

2. **Gaps Remaining for Production / Pilot Gate**:
   - **Playwright / Browser E2E**: Although UI components exist for all 36 capabilities, automated browser testing currently covers only `tests/e2e/access-shell.spec.ts`. End-to-end browser navigation across mobile/tablet/desktop viewports remains to be run.
   - **Hardware Scanning**: `SFL-05` scan routing and manual QR code entry are verified in unit/integration tests, but physical device camera scanner stream decoding requires real hardware device testing during the pilot.
   - **Multi-Instance Durable Deployment**: Deployment contract requires an approved single-writer architecture with persistent volume mounts for SQLite (Cloud Run ephemeral instances are strictly prohibited without persistent volume storage).
   - **Live Manufacturer Adoption**: SLAs (99.5% availability, P95 < 800ms CRUD) and business KPIs are target hypotheses that must be gathered during live pilot operations.
